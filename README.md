# Inventory-Management-System
Developed a command-line Product Management System using Python to efficiently manage product records. The system provides features for adding new products, viewing available products, searching records, updating product information, and deleting products. It uses JSON file handling for persistent data storage, ensuring that product information remains saved and accessible after the program is closed. This project demonstrates practical use of Python programming, file handling, data management, functions, and menu-driven application design.
